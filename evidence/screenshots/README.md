# Sanitized Screenshot Evidence Manifest

This directory contains 18 **sanitized derivative screenshots** from an authorized, isolated lab. SHA-256 values below identify the exact PNG derivatives in this repository; they are not hashes of original captures. Original screenshots, acquisition metadata, raw Responder logs, PCAP, Suricata `eve.json`/`fast.log`, and Windows/Sysmon EVTX exports are not included, so this set does not provide a complete forensic chain of custody or independent packet/endpoint confirmation.

All visible host, user, domain, interface, and poisoned-host labels—including `DC01`, `kali`, `mowgli0242`, `JTWYMAN`, `Administrator`, `jtwyman.test`, `eth1`, and `httpcapture2026live`—are synthetic identifiers used only in the lab. IP addresses are isolated-lab addresses. Redaction bars are intentionally opaque; no claim is made that underlying values can be recovered from these derivatives.

## Missing primary evidence

The following evidence remains explicit and unresolved; it must not be reconstructed or described as present:

- scoped PCAP;
- Suricata `eve.json`, `fast.log`, and rule/configuration snapshot;
- raw Responder session log;
- Windows Security and System EVTX exports;
- Sysmon EVTX export;
- target-side service, process, registry, and uploaded-file evidence.

For any future collection, preserve the original export outside the public repository, record acquisition context and time-zone information, calculate SHA-256 before transformation, and record each redaction/derivative step. Publish only reviewed derivatives and retain an original-to-derivative provenance record.
